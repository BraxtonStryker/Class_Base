Beta

Use quotes for an exact phrase. / jumps to search, ↑↓ move through results, Enter opens the slide or book page, Esc closes it.

    Add files

    Drop slide decks, a textbook, note sheets or practice questions (PDF) here. They're indexed in your browser: searchable and viewable right away, no rebuild needed. Landscape PDFs are treated as slides and portrait PDFs as books; short ones and files named like notes or cheat sheets as note sheets. You can switch that below. Added files are remembered in this browser when it allows storage, but for an exam, build them into the file instead.

    Drop PDFs here, or click to choose

    An exam reference page made with InfoBase or Class Base (an .html database with its definitions and formula sheet) can be added here too.

    Text is extracted page by page; scanned PDFs without a text layer will be viewable but not searchable.

    Download for offline (top right) saves the app and this class's PDFs as one HTML file that opens on any computer with no internet, for example on an exam laptop.
